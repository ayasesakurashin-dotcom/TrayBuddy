# AI 与角色配置解耦（2026-10-25，源码新增）

## 配置边界

- AI 功能开关、对话/识图/语音/记忆服务、语速、用户称呼和回复字数上限继续全局保存。
- `settings.characters[mod_id]` 保存角色称呼、人格、朗读语言及声音 ID。通用能力只接收解析后的 `RuntimeProfile`。`presets.rs` 单独保留内置艾玛数据，旧声音字段只用于其兼容默认值；通用语音翻译不再有固定艾玛入口。
- 未配置的新角色使用中性人格和跟随原文的朗读语言，不继承其他角色声音。记忆 bank、身份文件、SQLite、历史字段和输入草稿键保持兼容，没有新增分角色会话。
- 切换角色会取消旧回复、保留输入框开关并刷新当前角色配置。设置、输入框、菜单和导出提示使用通用名称。

## 本地暂存与显式上传

`voice_library.rs` 只处理本地文件，不依赖服务凭据或网络。系统文件选择器选定 WAV/MP3 后，先验证整批录音，再复制到 `companion/voice-samples/<角色标识的 SHA256>/`。列表保留原文件名，音频使用内容散列作为内部标识，重复内容去重。素材读取校验大小、文件类型和内容散列；素材操作使用后端生成的标识，而不是前端传入的任意路径。每角色最多 8 段、每段 8MB、总量 20MB。

导入、读取暂存列表、试听、取消和移除均不会创建远端声音。UI 在确认面板固定本次的角色、素材及服务地址，用户点击“上传并创建私有声音”后才提交。预设与本地素材合计选择 1—8 段、最多 20MB。服务端识别录音，不使用角色台词猜测逐字稿。

创建流程沿用 [Fish Audio 创建声音接口](https://docs.fish.audio/api-reference/endpoint/model/create-model)，请求指定私有声音，并校验响应确认私有后才采用。录音上传前会展示目标服务地址；仅保存设置或测试连接不会上传这些参考录音。

网络请求前固定角色；在请求前角色已经切换则停止，在请求期间切换则只绑定原始角色。写回声音 ID 时串行读取并保留最新设置；如果原角色的声音已被手动修改，则返回新声音 ID 供手动采用，不覆盖现值。每次创建的来源记录单独保存，避免不同角色互相覆盖。创建成功和失败均保留暂存录音；移除本地素材只影响本机副本。

## 后续小改：搜索不确定时的默认值

网页搜索设置新增“无法判断时默认搜索”，保存为全局 `web_search.search_when_uncertain`。新配置和缺少此字段的旧配置均默认关闭。搜索总开关关闭时此选项禁用，但保留用户选择。

路由协议更新为 v3：模型在 `direct/uncertain` 时可以提供公开查询候选词，由程序按保存的偏好决定是否搜索。关闭偏好时丢弃候选词，保持直接回答；开启后复用既有搜索与隐私校验。缺少候选词时先询问，不把聊天全文作为备用搜索词。明确不联网、个人记忆、天气、设备时间、已提供材料、情绪陪伴、创作和稳定常识的直接回答不受此设置影响；路由连接失败或结果格式错误仍按原流程提示。
