# 0.4.0 使用、升级与验证说明

发布日期：2026-10-24。此文描述已经验收的最终行为；早期设计稿中的预设关怀台词、固定节日表和三条总限额已由下列规则替代。

## 对话、观察与搜索

保持单一连续对话。对话与观察分表保存，按模型预算组织近期完整问答、观察引用及增量摘要；原文保留，可导出与遗忘。摘要失败不推进水位，历史变化使迟到结果失效。

输入框点击“屏幕”，选择外部窗口；发送时才抓取一次新画面，围绕当前问题识图并回答。“引用”使用已有观察文字，不重新截图；历史观察不能当作当前画面。原始截图与识图原始响应不落盘。定时观察独立设置，默认关闭。

网页搜索默认开启，无法确定需要搜索时不搜索。当前搜索适配经过验证的官方 DeepSeek 对话来源，其他兼容接口可正常聊天，但不会转发其密钥给搜索服务。每轮最多一次判断、一次搜索，不自动抓取页面或循环重试；查询不自动夹带截图、窗口标题或整份记忆。来源保存在该轮记录中，由“引用”入口查看。

分类或搜索故障时在输入框左下状态区提示。普通聊天可以继续；明确要求核查而未完成时保留未核查状态，不伪造联网结论。错误提示不进入模型回复气泡、语音或历史。联网外部答案与网页材料不进入长期记忆或滚动摘要。

聊天与识图模型分别设置思考强度，默认关闭。兼容接口可选择其支持的参数格式；不能关闭思考的服务仍受服务端能力限制。思考正文不进入气泡、语音或历史。

## 共享环境与通用关怀

设置支持固定关注城市，或自动位置模式。自动模式依次使用获准且有效的 Windows 设备定位、备用城市、获准且经确认的 IP 估算城市。设备定位和 IP 兜底默认关闭；城市必须从查询结果中选定。不会保存精确坐标或移动轨迹，固定城市不表示用户身在当地。

天气统一核验地点、来源时间及接收年龄。wttr.in 缺少完整观测时间时可使用 Open-Meteo 当前天气估算备用来源，并标明依据；不用接收时间伪装成观测时间。未核验或过期的预览不能支持当前天气断言和关怀。

自动关怀默认关闭；关闭时旧版关怀也不自行播放。启用后由触发器提供事实，使用当前角色人格生成简短回复，并按语音设置合成声音，不调用预设关怀语音。人格、朗读语言、声音 ID 按角色独立保存，通用触发器不包含艾玛人格。

- **天气与冷热**：默认 ≤5°C 或 ≥30°C，可调整；支持雨、雪、雾、霾、沙尘、雷暴、冻雨/冰粒和强风等有资料依据的情况。
- **日历节日**：显式联网导入并存到本地，未导入对应年度时不触发。中国日历使用香港天文台年度公农历对照，其他国家使用 Nager.Holidays 全国公众节日。传统节日与当地全国公众节日默认参与，二十四节气可选；周末、调休工作日不产生节日祝福。
- **晚间休息**：保留现有夜间时段；跨午夜视为同一夜间。
- **特殊日期**：可手动维护。对话中明确自述自动保存并在状态区告知；含糊或冲突时询问。生日/纪念日默认每年重复，个人安排默认一次；未说明农历时按公历保存。相对日期以消息处理时的本地日期解析，农历匹配依赖已导入的对应年度。

任意两条关怀至少间隔 45 分钟；四类各自滚动 24 小时最多两条，互不占用类别额度。特殊日期优先，其余候选随机选择；天气子类各 8 小时冷却并按同日同地点去重。队列最多三条，随机等待 20—120 秒，天气最多保留五分钟，其余最多十分钟；过期丢弃。

编辑、中文组合输入、提问、阅读或播放回复优先，会撤销关怀并进入约 120 秒安静期。隐藏、锁屏和免打扰时不显示，显示前复核事实与角色。“空闲”仅表示没有与桌宠交互，不判断用户是否在其他应用工作。

实际显示的模型关怀进入本地连续历史，不自动同步长期记忆。原生登录、普通随机动作和其他非关怀活动独立运行，不计入对话历史或记忆；它们占用演出时，关怀继续等待。Mod 自定义关怀可通过 `care_category` 声明。

## 气泡与语音

“特殊日期已保存”等系统提示只显示于输入框状态区，不参与语音合成。内部发言 ID、搜索指令或错误状态不作为正文显示。

启用且配置有效的语音在准备完成后，与文字气泡从实际播放事件同步开始；关闭语音、静音或语音请求失败时直接呈现文字。朗读语言按角色设置生效，日语翻译独立校验，完整保留回复内容。每片最多 80 个字素和三次显式换行，完整显示后停留四秒再继续；语音结束不会截断后续文字页。停止、切换角色或新请求会使旧回调失效。

## 升级与数据

先退出旧桌宠再安装或解压新版本。应用标识仍为 `com.traybuddy.cafel`，沿用已有数据目录和 API 配置。安装包为 Windows x64 当前用户安装模式，便携 ZIP 需要完整解压后运行 `traybuddy.exe`。运行需要 WebView2。

备份时退出程序并保存完整应用配置目录，包括 `companion/identity.json`、数据库及其 WAL/SHM 文件。设置 schema 与 SQLite 迁移前创建备份；凭据继续用 Windows 当前用户 DPAPI 加密。不要删除身份文件重建 bank，不要混用不同桌宠的身份和数据库。日历与特殊日期位于独立的 `care/` 数据目录，清空聊天不删除这些日期。

专用记忆 bank 仍与其他工作区隔离，每次远端操作验证所有权。不自动把生成的祝福当成用户事实。Hindsight 为可选独立服务，服务离线时保留本地上下文；软件不附带个人密钥、历史、定位或日历。

## 验证范围

- 前端：33 个文件、821 项通过。
- 后端：677 项通过，1 项可选真实 Hindsight 测试忽略。
- 用户已确认天气、搜索、日期保存、气泡语音和当前架构的实机验收。
- 正式发布前重新构建生产页面与启用 `custom-protocol` 的 Windows release 程序，检查 ZIP 与 NSIS 内实际可执行程序的内嵌资源、文件集合和 SHA-256；最终结果随 Release 的 manifest 与校验文件提供。
- 全量 Svelte 类型检查仍有 9 个原有文件中的 535 项错误、0 警告，不能表述为全项目类型检查通过。

默认回归使用临时数据库和公开日历样例，不调用用户付费模型、语音接口或现有记忆 bank。自动检查不替代所有设备、DPI、网络、账号权限和长时间运行场景的人工测试。临时探针、调试可执行文件及逐次调试日志不随发布包提供。
