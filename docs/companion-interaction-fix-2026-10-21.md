# 0.3.1 输入框与长回复交互优化

日期：2026-10-21。

## 问题

实机反馈包括输入框跟随拖动滞后、关闭后仍残留窗口、重新开启后尺寸或位置异常，以及 AI 回复在语音合成后重复弹出。旧有总字数与 token 限制也无法满足长回复。

## 当前行为

- 桌宠窗口的移动、尺寸与 DPI 事件驱动输入框同步；移动只更新位置，完整布局另行更新，并保留每秒一次的兜底检查。
- 输入框开关控制原生窗口显隐，恢复时同步当前位置与展开/收起尺寸；收起偏好及草稿继续保留。
- `reply_max_chars = 0` 表示不设应用总字数上限，新配置默认 0；正整数为用户自定义上限。已有配置的上限继续保留，可在设置中改为 0。
- 对话请求采用 SSE 流式输出，不再传固定 300 token。模型与服务自身的生成限制仍生效；忽略流式参数的兼容服务可返回一次完整 JSON，无需重新请求。
- 一条回复按同一 ID 与请求代次累计更新；完成、失败及停止均有终止事件。语音翻译与播放不重新显示回复，回复队列显示期间抑制预设事件气泡覆盖。
- 气泡按内容顺序呈现，优先在句子、标点与空白处断开，每片最多 80 个字素和 3 次显式换行。当前片逐字呈现，完整显示后保留 4 秒，再继续下一片直至末尾。
- 每片显示及长语音播放会续期当前请求的短租约，自动屏幕观察等待阅读与播放结束，避免长回复被打断；旧请求无法续期或释放新请求的租约。
- 最终完整中文回复写入聊天记录；日语翻译移除旧有 240 字与固定 token 限制。流式脱敏会暂缓显示尚未完整到达的疑似凭据。

## 验证记录

- 前端全量 29 个文件、771 项测试通过，包括流式分片与尾段、字数上限、输入框显隐与草稿、语音去重、取消、阅读租约、预设气泡异步覆盖和点击补全后的阅读时间。
- 后端全量 591 项通过；1 项需要显式授权的真实 Hindsight 测试保持跳过。新增覆盖 SSE UTF-8 字节边界、EOF、非流式兼容、可选字数限制、DPI 物理坐标和请求阅读租约。
- 前端生产构建通过。全仓 Svelte 检查仍为原有 9 个文件、535 条错误，本次修改文件没有新增诊断；全仓类型检查未通过。
- Windows 0.3.1 生产程序构建通过，启用 `custom-protocol`；便携包成品检查通过：80 项内置资源，动画、输入框、设置三个页面及其 13 项依赖完整。
- 当前用户 NSIS 安装包构建通过，安装程序载荷再次通过成品检查。便携 ZIP 包含 332 个文件，包内程序 SHA-256 与构建记录一致；安装包单独记录 NSIS 处理后的载荷校验值。没有执行安装覆盖。

首次沙箱测试被本机 HTTP 与临时文件替换限制阻断，普通权限下重新运行通过。全量 Rust 测试在标准 `src-tauri` 工作目录执行；在仓库根目录运行会受到既有默认气泡样式测试对当前目录的依赖影响。

没有调用个人配置中的付费模型、语音或真实 Hindsight 服务，也没有覆盖已安装程序。隔离浏览器验证页已准备，但当前无可用浏览器会话，headless Edge 未生成截图，因此未完成视觉验收。桌面拖动手感、跨显示器操作及真实语音须以新包实机复测为准。
