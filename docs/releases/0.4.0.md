# Ema Desktop / TrayBuddy 0.4.0

2026-10-24，Windows x64。

本版整合连续上下文、当前屏幕提问、按需搜索、环境资料与通用自动关怀，并修复实机反馈中的气泡和语音问题。

## 新增与改进

- 对话与观察分存，支持增量摘要、观察引用、完整导出与遗忘；输入框可选择“带上当前屏幕”，发送时围绕问题观察所选窗口。
- 按需网页搜索默认开启，无法确定需要搜索时不搜索。搜索故障显示于输入框状态区，不进入气泡或语音。当前搜索适配官方 DeepSeek 对话来源。
- 聊天和识图模型独立设置思考强度，默认关闭；人格、朗读语言和声音配置按角色保存。
- 统一环境资料服务，支持固定城市、Windows 定位及经确认的 IP 兜底，补齐天气时间校验与备用估算来源。
- 自动关怀支持天气、日历节日、晚间和特殊日期，触发与具体人格分离，回复由当前角色模型生成。可导入国家/年度日历，支持公农历对照和对话保存特殊日期。
- 关怀共享 45 分钟间隔，每类滚动 24 小时最多两条，特殊日期优先；普通登录与随机活动独立运行，不进入对话历史或记忆。
- 修复发言 ID 回显、搜索时仅显示“查询”的短首屏、日语朗读语言失效、后续文字气泡缺失和文字语音起播不同步。“特殊日期已保存”等系统提示只出现在状态区。

## 下载与升级

- `traybuddy_0.4.0_x64-setup-user.exe`：当前 Windows 用户安装包。
- `ema-desktop-0.4.0.zip`：完整便携版，全部解压后运行其中的 `traybuddy.exe`，不要单独复制 EXE。

先从托盘退出旧桌宠，再安装或启动新版。需要 Windows 10/11 x64 和 Microsoft Edge WebView2。应用标识与配置目录不变，沿用已有设置、Mod、对话与专用记忆身份；设置和数据库迁移前保留备份。建议退出程序后备份完整应用配置目录，不要删除记忆身份文件。

自动关怀、定时观察、设备定位与 IP 兜底默认关闭。日历需在设置中主动导入；特殊日期独立保存，清空聊天不会删除日期。软件不附带个人 API 密钥、对话历史或日历。
