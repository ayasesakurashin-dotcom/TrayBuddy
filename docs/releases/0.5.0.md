# Ema Desktop / TrayBuddy 0.5.0

2026-10-25，Windows x64。

本版将 AI 功能与具体桌宠人格分离，增加本地音声暂存，并允许调整搜索判断不确定时的默认行为。

## 新增与改进

- 对话、识图、搜索、自动关怀及接口配置全局共用；人格、角色称呼、朗读语言和声音按桌宠角色分别保存。切换角色会读取对应配置，新角色使用通用默认人格，现有艾玛配置继续兼容。
- 支持导入 WAV、MP3 音声到本地暂存，关闭设置或重启后保留。可试听、移除、与角色预设素材混合选择；导入不上传，只有核对素材和服务地址、明确点击“上传并创建私有声音”后才提交到已配置的 Fish Audio 服务。
- 声音创建失败保留原声音和本地素材；请求期间切换角色时只绑定原始目标角色，不覆盖其他角色或手动修改的声音设置。
- 网页搜索增加“无法判断时默认搜索”，默认关闭以兼容旧设置。开启后使用公开候选关键词尝试查询；搜索总开关关闭或本次明确要求不联网时不搜索，缺少公开关键词时先询问。
- 删除重复的“艾玛的人格”，统一设置页、输入框、菜单和导出提示。切换桌宠保留输入框开关并结束旧角色回复。
- 输入框跟随角色与可见边框的显示区域底部，保留 8 个逻辑像素间距；拖动、缩放、显示缩放及收起/展开时更新定位，减少透明留白造成的过大间距。
- 发布文件按版本分别归档，便携包和安装包附带当前使用说明及版本文档。

## 下载与升级

- `traybuddy_0.5.0_x64-setup-user.exe`：当前 Windows 用户安装包。
- `ema-desktop-0.5.0.zip`：完整便携包，全部解压后运行其中的 `traybuddy.exe`，不要单独复制 EXE。

先从托盘退出旧桌宠，再安装或运行新版。需要 Windows 10/11 x64 和 Microsoft Edge WebView2。沿用原应用标识与配置目录，保留已有人格、声音、Mod、设置、连续对话及记忆身份。各桌宠角色仍共用现有记忆 bank 和会话，本版未拆分记忆库。建议退出程序后备份完整应用配置目录，不要删除身份文件重建 bank。

每个角色最多暂存 8 段录音，单段 8MB、总量 20MB；创建声音时预设和导入素材合计最多 8 段、20MB。移除本地素材不会删除已创建的远端声音。安装包与便携包不包含个人音声、API 密钥、对话历史或记忆文件。

## 验证与已知限制

前端 34 个文件、837 项测试通过；后端 689 项通过，1 项可选真实 Hindsight 服务测试忽略。成品核验安装包与便携包的内嵌生产页面、文件内容及 SHA-256；校验明细见附件 `ema-desktop-0.5.0-release-manifest.json` 和 `SHA256SUMS-0.5.0.txt`。

全量 Svelte 类型检查仍有原有 9 个文件中的 535 项错误、0 警告，本次修改文件没有新增类型诊断。测试未向真实 Fish Audio 上传录音，不验证不同账号的音色效果。网页搜索仍适配官方 DeepSeek 对话接口，其他服务可正常聊天；路由连接或格式失败保持原有失败提示。自动关怀及定时观察的既有开关和频率规则不变。
