# AI 桌宠使用与数据说明

当前版本 **0.5.0（2026-10-25）**。新增角色解耦、音声本地暂存和搜索默认策略，升级与验证见 [0.5.0 说明](docs/releases/0.5.0.md)。基础机制见 [上下文与关怀说明](docs/companion-0.4.0.md)。

## 开始使用

1. 从 [本 fork 的 Release](https://github.com/ayasesakurashin-dotcom/TrayBuddy/releases/tag/v0.5.0) 下载当前用户安装包或完整便携 ZIP，先退出旧桌宠，再运行新版本。
2. 在设置中配置聊天 API 的地址、模型名与密钥，保存并测试连接。模型名和权限以服务商及账号实际支持为准。
3. 通过模型下方输入框聊天，Enter 发送、Shift+Enter 换行。收起保留草稿和回复；字数上限设为 0 表示不限。
4. 需要语音时配置 Fish Audio 地址、模型、密钥及声音 ID，选择朗读语言并试听。人格、角色称呼、朗读语言和声音按角色保存，艾玛保留原兼容默认值。
5. 需要图片能力时独立配置识图 API。定时观察默认关闭；也可在输入框点“屏幕”选择本次问题的外部窗口，发送时获取新画面。

输入框和 AI 语音默认开启，接口未配置时保持待配置状态。网页搜索默认开启；“无法判断时默认搜索”默认关闭，可在网页搜索设置中开启，使模型不确定时也尝试搜索公开资料。无法提炼公开查询词时先询问；搜索总开关关闭或本次明确要求不联网时不搜索。当前搜索适配官方 DeepSeek 对话来源。聊天与识图的思考强度独立设置，默认关闭。

配置有效且启用语音时，气泡与声音从实际起播时同步开始；未启用或语音失败时直接显示文字。长回复逐页显示到末尾，语音结束不会截断文字。搜索失败与“特殊日期已保存”等提示位于输入框左下状态区，不进入回复气泡或语音。

## 角色与声音素材

所有角色共用 AI 接口、功能开关、记忆 bank 和连续对话历史。设置中的“当前角色人格与声音”控制当前角色的称呼、人格和朗读语言；切换角色会读取其独立配置，新角色使用通用默认人格。更换对话模型不会重置这些配置。

在“生成语音”点击“导入音声到本地暂存”，选择 WAV 或 MP3 录音。导入只复制到当前角色的本地素材库，不上传、不创建声音、不替换声音 ID，也无需先配置语音 API。每个角色最多暂存 8 段，单段不超过 8MB、总量不超过 20MB；关闭设置或重启后保留。支持试听与移除；源文件移动或删除后仍可使用已暂存副本。

勾选暂存录音或角色预设素材，点击“用所选素材建立私有声音”，核对目标角色、文件列表及服务地址。点击“继续暂存”不会发送请求；只有点击“上传并创建私有声音”才会将所选音声提交至已配置的 Fish Audio 服务。创建成功后更新对应角色的声音 ID；失败保留原声音及本地素材。创建期间若手动修改了该角色声音 ID，则不自动覆盖，界面会提供新 ID。移除本地素材不删除已创建的远端声音。

## 环境、日历与自动关怀

打开“环境与自动关怀”设置，选定固定城市，或启用自动位置模式。Windows 定位与 IP 兜底默认关闭，IP 城市需确认。天气由共享服务核验地点与时效，备用估算来源会标明。

自动关怀默认关闭。开启后分别由天气、导入日历节日、晚间与特殊日期触发，使用当前角色生成回复及声音。任意两条至少相隔 45 分钟，每类滚动 24 小时最多两条，特殊日期优先。编辑、提问、阅读与语音播放时避让；不会判断用户在其他应用中是否忙碌。

在“日历设置”联网导入国家和年份，之后保存在本地使用；没有导入日历时不启动节日关怀。传统节日与全国公众节日默认参与，二十四节气可选。特殊日期可手动维护，也可在对话中明确自述后自动保存；含糊或冲突时询问。生日和纪念日默认每年重复，个人安排默认一次，未说明农历时按公历保存。

实际显示的关怀进入本地连续聊天历史，不自动同步长期记忆。普通登录、原生随机动作与关怀分开，不进入对话历史或记忆。

## 记忆与数据安全

Hindsight 默认根地址为本机 http://127.0.0.1:18088，只接受本机服务。首次生成随机持久的专用 bank ID 与所有权标记，界面只读；每次操作验证归属，不扫描其他 bank，不回退到 default 或其他工作区。

对话与观察分表保存，并通过预算和增量摘要组织上下文。长期记忆离线时保留本地原文与同步队列。联网外部答案、网页材料及生成关怀不自动同步长期记忆。设置支持历史导出、单条遗忘和清空；遗忘后阻止旧异步结果重新写回。

应用沿用 com.traybuddy.cafel 标识和配置目录。companion 子目录包含身份、设置、history.sqlite、Windows DPAPI 加密凭据和声音来源记录；voice-samples 子目录保存按角色分开的本地音声副本，voice-provenance 子目录保存每次创建声音的来源记录；care 子目录保存日历、特殊日期及关怀记录。迁移前自动保留设置与数据库备份。备份时退出程序并复制整个配置目录，身份必须与对应数据库及运行文件一起保存。跨 Windows 用户或设备后通常需重填密钥。

身份不匹配或数据损坏时保留原件并暂停 AI，原桌宠继续运行；不要删除身份文件来重建连接。Hindsight 服务自身的模型可能使用云端 API。屏幕图像只在内存中处理并发送到已配置识图服务，不保存原图。

## 开发与验证

构建和测试命令见 [源码 README](https://github.com/ayasesakurashin-dotcom/TrayBuddy/blob/v0.5.0/README.md#从源码开发与构建)。正式程序必须启用 custom-protocol，内嵌页面后可脱离开发服务器运行。scripts/verify-release-package.ps1 在读取个人配置、创建窗口和启动服务前退出，只检查实际程序内嵌资源。

Windows 单元测试使用 scripts/test-companion-windows.ps1 处理 Common Controls v6 manifest；真实 Hindsight 测试是显式可选项，默认不运行。0.5.0 验证为前端 837 项、后端 689 项通过，1 项真实服务测试忽略。Svelte 类型检查仍有原有 535 项错误、0 警告，不能声称全项目类型检查通过。

本项目保留 TrayBuddy 的动画、Mod、预设活动、工具、备忘录和提醒。AI 直接访问用户配置的服务，不连接其他本机智能体，也不提供通用命令执行或设备任务代理。
